# sheet-widget
 - интерактивный модуль таблиц, который интегрируется в платформу как самостоятельный miniapp-плагин.
 - является проектом для системы совместного обучения УрФУ.

## Как запустить локально?
### Установка проекта
Откройте терминал и выполните перейдите в каталог в который хотите установить проект:

``git clone https://github.com/Sea-fish001/sheet-widget.git``

Откройте проект с в Pycharme и перейдите в папку проекта:

``cd sheet-widget``

### Запуск backend-части
Перейдите в папку:

``cd backend``

Создайте виртуальное окружение:

``py -m venv venv``

Активируйте его:

``.\venv\Scripts\activate``

Файл requirements.txt должен быть в репозитории. Установите зависимости:

``pip install -r requirements.txt``

Примените миграции:

``python manage.py migrate``

Примечание: makemigrations выполнять не нужно — все миграции уже в репозитории.

Запустить backend:

``python manage.py runserver``
